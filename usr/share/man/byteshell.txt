byteshell - the ByteOS shell

ByteShell is the login shell. It takes its cues from fish: the line is
coloured as you type, grey suggestions come from your history, and Tab
completes.

EDITING
  Up / Down        history; with text typed, only lines containing it
  Right End ^F     take the grey suggestion
  Tab              complete commands, files, $VARIABLES, package names
  ^A ^E            start / end of the line     ^U ^K  cut to start / end
  ^W               cut the word before the cursor
  ^L               clear the screen            ^C     cancel the line
  ^D               on an empty line: log out

COMMAND LINES
  a; b             one after the other
  a && b           b only if a succeeded       a || b   b only if a failed
  not a            invert a's status           $status or $?  last status
  a | b            a's output becomes b's input
  a > file         write the output to file    >> appends    < file reads
  a &              run in the background (the whole a && b || c list)
  * ? [abc]        match file names; 'quoted' or \* stays literal
  'single'         everything literal          "double"  $VARS expanded
  $(cmd)           what cmd prints: unquoted one word per line, in
                   "double quotes" all of it as one word
  ~                your home directory         # rest    a comment
  dir/  ..         typing a directory changes into it (auto-cd)

VARIABLES
  NAME=value       set a variable (names are UPPERCASE)
  set NAME value   the same, fish style; set -e NAME erases it
  export NAME=v    the same; every variable is exported
  env              list them; env NAME=v cmd runs cmd with NAME set
  USER and HOME are read-only: who you are is kept by the kernel.

FILES
  /etc/profile     run at every login (for everyone)
  ~/.shrc          run at every login, after /etc/profile; set aliases
                   and variables here (GREETING= turns the greeting off)
  ~/.profile       run once per login, after ~/.shrc (su skips it,
                   su - runs it)
  ~/.byteshell_history   your history (500 lines; a command that starts
                   with a space is not saved)

BLOCKS (as in fish; statements end at ; or a new line)
  if CMD; ...; else if CMD; ...; else; ...; end
                   runs the part whose CMD succeeds (status 0)
  while CMD; ...; end
                   repeats while CMD succeeds
  for NAME in WORDS; ...; end
                   once per word: for F in *.txt; echo $F; end
  function NAME; ...; end
                   a new command; $1.. $# $@ are its arguments
  begin; ...; end  a group of commands
  break  continue  leave a loop / go on with the next round
  return [n]       leave a function (or a script) with status n
  and CMD  or CMD  run CMD only if the last status was 0 / was not 0
  end > file       after end: < > >> apply to the whole block, e.g.
                   while read LINE; echo $LINE; end < notes.txt
  At the prompt an unfinished block asks for more lines; ^D drops it.
  Ctrl+C stops a loop. Loop variables are UPPERCASE like all variables.

SCRIPTS
  A text file of command lines and blocks. With #!/bin/sh as its first
  line it runs by name (./script); otherwise use sh script. Inside: $0
  the script, $1..$9 its arguments, $# how many, $@ all of them; exit n
  or return n ends it. A line ending in \ continues on the next one.

    #!/bin/sh
    for F in $@
      if test -f $F
        echo "$F: $(wc -l < $F) lines"
      else
        echo "$F: not a file"
      end
    end

BUILT-IN COMMANDS
  cd [dir|-]               change directory; - goes back
  alias [name[=value]]     list or define aliases: alias ll='ls -l'
  unalias name... | -a     remove aliases
  source file | . file     run a file in this shell
  history [search t|clear] show, search or clear the history
  set, export              variables (see above)
  jobs                     this session's background jobs
  wait [%job|pid]          until background jobs have finished
  fg [%job]                wait for a job in the foreground (the newest
                           one without an argument); Ctrl+C stops it
  exit [n]                 leave the shell (or a script, with status n)
  logout                   back to the login prompt
  not cmd                  run cmd and invert its status
  true  false              succeed / fail, nothing else
  test EXPR  [ EXPR ]      check something; status 0 if true:
                             -e -f -d -s FILE  exists / file / directory /
                                               not empty
                             -z -n STR         empty / not empty
                             A = B  A != B     strings
                             A -eq -ne -lt -le -gt -ge B   numbers
                             ! ( ) -a -o       not, grouping, and, or
  read [-p P] [-s] NAME... one line into NAME (more names: one word each,
                           the rest into the last); from a pipe, a file
                           (end < file) or the keyboard with prompt P;
                           -s hides the typing; status 1 at the end
  math EXPR                calculate: + - x / // % ^ ( ), floor ceil abs
                           sqrt min max; math $I + 1  (x multiplies: an
                           unquoted * would be a wildcard)
  functions [-e NAME]      list the functions, or erase one
